🚀 ResiliLytics — SME-Native Resilience Intelligence Dashboard

ResiliLytics is an SME-native resilience analytics dashboard with an AI-assisted decision framework.

It transforms minimal supplier inputs into a multidimensional resilience index using a weighted, inference-based modeling structure designed specifically for Small and Medium Enterprises (SMEs).

Rather than functioning as a static KPI dashboard, ResiliLytics operates as a structured decision-intelligence framework that converts supply-chain risk signals into prioritized action pathways.

📊 How the Resilience Model Works

ResiliLytics uses a structured 7-factor multidimensional scoring framework.

Each component is normalized to a 0–100 scale
(100 = stronger resilience | 0 = higher risk)

🔹 Core Components

SCR (25%) – Supplier Concentration Resilience

GPR (15%) – Geographic Portfolio Resilience

LTV (20%) – Lead-Time Stability Proxy

CVS (15%) – Cost Volatility Sensitivity

BIS (10%) – Buffer Inventory Strength Proxy

ASS (10%) – Alternative Sourcing Strength

FMS (5%) – Financial Margin Sensitivity Proxy

🔁 Adaptive Weighting Logic

If supplier concentration exceeds 50%, the model automatically activates Adaptive Concentration Mode:

SCR weight increases

Margin sensitivity receives higher weight

Volatility-related weights rebalance

This prevents underestimating fragility when structural dependency is high.

The system therefore operates as a contextual scoring engine — not a static formula.

📐 Academic Weight Justification (SME-Calibrated)

The weighting structure reflects empirically observed disruption patterns in SMEs.

Supplier concentration (25%) carries the highest base weight due to its disproportionate impact on operational continuity.

Lead-time stability (20%) and geographic exposure (15%) capture timing and regional clustering risks.

Cost volatility (15%) reflects margin pressure dynamics.

Buffer readiness (10%) and alternative sourcing strength (10%) function as structural shock absorbers.

Financial margin sensitivity (5%) is weighted lower because financial strain typically follows operational instability.

When supplier concentration exceeds 50%, adaptive reweighting increases emphasis on concentration and margin sensitivity to reflect heightened fragility.
